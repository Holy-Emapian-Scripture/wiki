# Gradiente

O gradiente $\nabla$ de $f:{\mathbb{R}}^{n} \rightarrow {\mathbb{R}}$ é:

$$\nabla f = \left( \frac{\partial f}{\partial x_{1}},\ldots,\frac{\partial f}{\partial x_{n}} \right)$$ <a id="equation_definition_gradiente"></a>
